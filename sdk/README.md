# Kasrah Games SDK v2.6.0

الـ SDK الرسمي لمنصة **ألعاب كسرة** (Kasrah Games). يوفر هذا السكربت تكاملاً سهلاً للألعاب مع المنصة، بما في ذلك شاشات التحميل، الإعلانات، حفظ البيانات سحابياً، والتحليلات.

## 🚀 المميزات الجديدة (v2.6.0)
- **معالجة متقدمة للأخطاء:** نظام `try-catch` شامل يضمن عدم توقف اللعبة عند حدوث أخطاء في السكربت.
- **وضع التطوير (Debug Mode):** رسائل ملونة وواضحة في الكونسول لمساعدة المطورين على تتبع الأحداث.
- **نظام التحليلات (Analytics):** تتبع تلقائي لأحداث بدء اللعبة، الإعلانات، ومزامنة البيانات.
- **التحقق من البيانات (Validation):** حماية من حفظ بيانات تالفة أو ضخمة جداً (حد أقصى 2MB).
- **نظام الأحداث (Event System):** إمكانية الاستماع لأحداث الإعلانات والتحميل للتحكم في اللعبة.

---

## 🛠️ كيفية التثبيت

أضف السكربت التالي في ملف `index.html` الخاص بلعبتك:

```html
<script src="/sdk/kasrah-sdk.js"></script>
```

## 📖 دليل الاستخدام السريع

### 1. التهيئة المخصصة (Manual Initialization)
إذا كنت تريد التحكم في إعدادات الـ SDK، استخدم `manualInit`:

```javascript
KasrahSDK.manualInit({
    adFrequency: 3,        // عرض إعلان كل 3 طلبات
    autoPlayDelay: 5000,   // بدء اللعبة تلقائياً بعد 5 ثواني
    debugMode: true,       // تفعيل رسائل التصحيح (ينصح به أثناء التطوير)
    enableAnalytics: true  // تفعيل نظام التتبع
});
```

### 2. الاستماع للأحداث (Events)
استخدم نظام الأحداث للتحكم في صوت اللعبة وحركتها أثناء الإعلانات:

```javascript
// عند بدء ظهور الإعلان
KasrahSDK.on('adStarted', () => {
    game.pause(); // إيقاف اللعبة
    game.mute();  // كتم الصوت
});

// عند انتهاء الإعلان
KasrahSDK.on('adFinished', () => {
    game.resume(); // استئناف اللعبة
    game.unmute(); // إعادة الصوت
});
```

### 3. حفظ وتحميل البيانات
الـ SDK يقوم بمزامنة البيانات سحابياً تلقائياً إذا كان المستخدم مسجلاً دخوله:

```javascript
// حفظ بيانات
KasrahSDK.saveData('highScore', 1500);

// تحميل بيانات
const score = KasrahSDK.loadData('highScore');
```

---

## 🧪 وضع التطوير (Debug Mode)
عند تفعيل `debugMode: true` في الإعدادات، ستظهر لك رسائل في الكونسول مثل:
- `[Kasrah SDK] INFO`: تتبع العمليات العادية.
- `[Kasrah SDK] SUCCESS`: عند نجاح المزامنة أو تسجيل الدخول.
- `[Kasrah SDK] ERROR`: عند حدوث خطأ مع شرح السبب.
